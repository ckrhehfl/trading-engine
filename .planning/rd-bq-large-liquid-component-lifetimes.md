ordinary-exit bounds. BP separately restored the missing LG/LX successor quotes
and three raw-close anchors. Those completed diagnostics did not establish

## Implementation under way

The basis-anchor diagnostic restores the original BM audit and separately pinned
BP extension, requires their independent receipts and the independent raw-row
extraction receipt, and projects precisely three fixed raw/adjusted pairs. It
does not fetch a new price or issue key. Exact Fraction arithmetic preserves
both price and reciprocal share-unit directions, including repeating ratios.
Typed original values, current retrieval provenance and unresolved historical
availability stay distinguishable. A price comparison is not an economic unit
certificate or custody-delivery finding.

The component proof starts with all original potential origins across both
timing arms and recomputes the existing ordinary proof. Canonical event terms
use the shared decoder and basis constructors before final interval coverage.
Terms-only validation is not complete action evidence. Its hash excludes final
coverage bytes so a file need not indirectly hash itself.

For a supported isolated compulsory spin-off, both components inherit the
original due date. Their price candidates respect each component's established
availability. The action interval ends at the later candidate; the full quote
union remains unchanged. Missing requests, unresolved rights, unsupported event
chains and unsupported eligibility paths retain the full original obligation.
Later independent parent purchases do not acquire the earlier allotted shares.
The final connector must recompute supplied proofs, validate complete inclusive
coverage, execute the existing replay once per arm, and check actual component
inventory against the proof. Unfilled potential origins need not create lots.

A separate committed logged caller, frozen specification, normal review/merge,
isolated research deployment, one registered actual proof and independent
verification precede using shorter coverage in the final actual pair.
