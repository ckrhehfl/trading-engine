## One low-degree calibration estimator

For each outer training cutoff compute the original full joint-known cohort J
and exact date -> symbol/session cluster -> original episode -> frame weights.
Only then condition on C, causal phase and the chronological OOF support. Four
phases retain original uncoalesced onset priority, waiting_pullback, pullback,
confirmation. A row enters common calibration support only when both original
net targets and fills are known/mature, and both OOF value heads are finite.
Keep original all-family weights; do not rebalance C or the retained OOF subset.
OOF prediction support is causal; known-outcome conditioning is training only.

For phase s and action a, compute weighted OOF prediction mean xbar[s,a] and
weighted OOF target mean ybar[s,a]. For each action fit one slope shared across
all four phases, with phase-centered weighted least squares:

    numerator[a] = sum_i w_i (x_i - xbar[s_i,a]) (y_i - ybar[s_i,a])
    denominator[a] = sum_i w_i (x_i - xbar[s_i,a])**2
    beta[a] = max(0, numerator[a] / denominator[a])
    calibrated(x,s,a) = ybar[s,a] + beta[a] * (x - xbar[s,a])

If positive support has exactly zero centered score variance, beta is zero
and the fitted constant is that phase's OOF target mean. Empty phase support
is unknown, with no pooled fallback. No additional support threshold or
regularization search. Positive but sparse support is descriptive and low
precision. There are two nonnegative slopes per outer fold, not eight freely
fitted slopes. These are net-value regressions, not probabilities.

The calibration intercept uses the OOF portion's target mean, not the full-J
EQ mean. This distinguishes fitting one coherent affine regression from
silently transferring a different population's intercept. Keep EQ full-training
means as the separate control. Report both supports and their difference.
Use exact rational weights/targets and exact decimal representations of saved
finite scores for sufficient statistics. Convert final stored calibration
statistics/predictions once with Decimal precision 50, ROUND_HALF_EVEN; exact
zero variance/covariance and policy ties must survive. Cash remains exact.

Apply the frozen mapping to all original causal C entry queries, not just
previously selected trades. Preserve original non-value heads and causal
unknowns. Nonnegative slopes preserve within-phase/action ordering, except
ties at zero slope; phase/action intercept changes can alter cross-phase
selection. Calibration cannot create new ranking information. A mapping fitted
to earlier models need not transfer perfectly to the outer fitted model.

## Pre-execution arithmetic clarification

An invented algebraic counterexample showed that rounding the three stored
center/slope statistics separately could turn an exactly zero projected value
into a small positive commitment. Store the exact rational slope and each
phase/action intercept (ybar minus beta*xbar) as canonical numerator/denominator
hex strings; this avoids decimal integer-string size limits without rounding.
Project with those exact coefficients and round only the final score to the
registered Decimal context. Rounded means/covariance/variance/slopes remain
descriptive artifact fields. This supersedes projection from rounded statistics,
not the registered estimator, native network, score threshold or cash rules.
The zero-variance constant is a predeclared minimum-slope solution with an
explicit nonidentified status, distinct from a negative-covariance constrained
zero. No performance outcome was read to make these arithmetic clarifications.
