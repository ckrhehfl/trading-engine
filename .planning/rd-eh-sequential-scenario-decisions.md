# Task EH sequential scenario decisions around important prices

2026-11-07. 운영자는 같은 중요 가격대에서 경쟁 경로를 예측하고 새 증거에 따라
대기·진입·유지·축소·청산·제한 재진입을 평가하는 Goal을 승인했다. 시점·장부
검증부터 진행하고, 기존 발견 자료의 지원 범위에서 예측과 행동을 나누어 평가한다.
동일 목표의 조건부 갱신, 변경된 질문, 실행 요청과 가상 체결을 각각 기록한다.

## 시작 범위

기존 CB의 당시 모집단과 CC/CX의 감사된 정규장 가격·거래량 원본을 대상으로 한다.
EG의 고변동 사건과 이후 확인으로 과거 접근 시점을 골라내지 않는다. 원래 전체
달력과 S1/S2를 분모로 보존한다. 첫 범위는 전 거래일의 지원된 고가다. 부분 관측의
최고가를 전일 전체 고가로 사용하지 않는다. 개장 범위와 장중 횡보 상단은 다음
후보이며, 이 초기에 동시에 조건을 탐색하지 않는다.

먼저 정확한 합성 사례에서 상태·미래 경로·가상 수량을 연결한다. 원본 시장 접근,
학습·관측·실행은 초기 소스 검증의 범위 밖이다. 실제 단위는 별도 사전등록에서
필요한 가격 이력, 현재 관측 폭, 진입 가격 상한, 경로 모델, 위험 평가와 비용 가정을
하나의 명세로 닫는다. 완료된 EE/EF/EG 단위를 재실행하지 않는다.

## 최초 합성 경로의 판단 계약

- 준비 상태의 가격대와 폭은 당시 완료·가용한 봉으로 고정한다. 지원불명, 갭으로
  앞선 시작 미관측, 진입 없음, 진입 거절과 확인된 진입을 구분한다.
- P1 직접 확장, P2 재시험 후 확장, P3 하단 선접촉, P4 기한 내 미결정을 구분한다.
  접촉 선후나 필요한 가격이 불명이면 미확인이다. 같은 시각에 아는 관측만으로
  갱신한다. 경계나 절대 종료가 바뀌면 별도 질문으로 기록한다.
- 기존 분봉 가용 가정은 완료+2분이다. 이 가정과 원래 수신 증거를 구분한다.
  일반 갱신은 완료 5분봉, 구조 무효화는 가용한 완료 1분 종가를 사용한다.
  미래 경로가 갈라지기 전 같은 관측은 같은 결정을 만들어야 한다.
- 판단 다음 분의 고정 시가에만 가상 요청을 대조한다. 미확인은 현금·잔량을
  보존하고 이후 매수를 막는다. 미래 시가를 보고 요청 수량을 늘리지 않는다.
  에피소드 종료는 최초 판단에서 최대 60분 및 마지막 유효 정규장 시가 이내다.
- 최초 예정 위험은 한 사건 예산의 절반 이내다. 상한 가격에서 사전 수량을 고정한다.
  청산된 각 조각의 순손실을 사건 예산에서 차감하고 이익으로 한도를 복원하지 않는다.
  33bp와 43bp는 과거 연결용 가상 왕복비용이다. 진입에서 한 번 낸 비용을
  축소와 잔량 청산에 배분한다. 이것은 실제 통화·수량·체결을 인증하지 않는다.
- 보유 중 최초 수량의 내림 절반을 최대 한 번 축소할 수 있다. 구조 무효화나 종료는
  모델 선택보다 우선한다. 청산 확인 후 독립된 새 근거와 잔여 시간·예산이 있는
  경우만 한 번 재진입한다. 최초 시도의 종료와 시나리오 판단을 소급 변경하지 않는다.

## 확인 순서와 조건부 후속

1. 상태·경로·수량을 발명 입력으로 검산한다. 결측, 순서 불명, 미래 노출, 한 주,
   부분 청산, 불명 체결, 진입 거절, 재진입과 시간 종료를 포함한다.
2. 실제 읽기 전에 정확한 whole-path 합성 자격을 통과한다. 현재 ordinary300 경로의
   로컬 whitelist에 EH 전용 등록을 추가해야 한다. Torch의 기존 소형 주소공간
   측정치는 일반 상한을 초과했다. 학습기를 지원한다고 간주하거나 EG 한도를 쓰지 않는다.
3. 원본 지원 감사에서 동일 모집단의 준비·무사건·불명, 전일·당일 지원, 독립 날짜와
   라벨 수를 보존한다. 결과의 관측 여부가 당시 기회 목록을 바꾸지 못한다.
4. 학습기간의 유사 경로 분포, 차트 시계열, 동일 지원에서 관측 동료 종목을 더한 모델을
   비교한다. 실제 학습 전에 시간순 분할, 중복과 라벨 성숙, 고정 가중치·횟수를 등록한다.
   경로 확률의 신뢰도와 불리한 움직임을 확인한다. 미래가 알려진 가상 최적 행동을
   실행 정책으로 평가하지 않는다.
5. 같은 초기 진입의 고정 청산과 동적 관리, 그 뒤 제한 재진입을 분리한다. 명목
   비용 전후, 손실 위험, 투자비중, 회전율·주간 빈도와 종목·시기 집중을 보고한다.
   손실 감소를 노출 감소와 구분하며 주 15회는 평가 기준으로 표시한다.

범위 내 결측과 작은 표본은 탐색 한계로 보존하고 영향을 받지 않은 확인을 계속한다.
새 자료나 자원으로 확대하기 전 실패 지점을 구체화한다. 조건부 후속은 관측된 병목
하나에 한해 사전등록하고, 원래 결과를 다시 쓰거나 양수가 나올 때까지 탐색하지 않는다.
정상 PR 머지·필수 CI·독립 소스와 연구 무결성 검토는 각 실행 릴리스에 적용한다.

## 2026-11-07 최초 소스 검증

가격대·경로·정책의 세 순수 모듈과 기존 현금 장부의 선택적 고정 수량 인자를 구현했다.
기존 인자 없이 호출한 장부의 산술과 한도는 유지한다. 새 인자는 판단 전에 고정한
수량만 체결하는 모델로, 가격이 좋아졌다고 수량을 늘리지 않는다.

합성 통합은 동일 관측에서 동일 행동 뒤 미래 라벨이 갈라지는 사례와, 준비→진입→
절반 축소→청산 확인→새 근거→재진입→원래 사건 종료를 연결했다. 효용과 체결가는
발명 입력이다. WSL Python3.12 지정 회귀는 최초 122개 통과, 기존 ignored 실험 로그가
없는 경우의 검사 한 개는 skip이다. 새 원본 조회·모델 학습·시장 손익 계산은 0이다.
최종 소스 검토·필수 CI·정상 머지는 이 기록 이후에 확인한다.

개발 검토에서 정책의 관측 시각 하한 누락을 발견해 완료+2분 이전 가격 사용을
차단했다. 지연해서 받은 진입 전 봉을 보유 중 구조 이탈로 처리하는 경우도
회귀로 고정했다. 실제 입력 실행 전에 발견한 소스 문제로 기록한다.

최종 무결성 검토는 늦은 사건의 종료가 세션 종료 시각과 같아질 수 있음을 발견했다.
사건 종료 상한을 마지막 세션 내 분 시가로 고정하고 짧은 세션 회귀를 추가한다.
기존 분 경계 제약이 초 단위 청산 입력을 거절하는 것도 회귀로 확인한다.
재진입 잔여 5분은 다음 가상 체결 시각을 기준으로 한다.

## 2026-11-07 자료 지원 감사 등록

초기 합성 경로는 PR #409에서 별도 소스·연구 무결성 검토와 필수 CI를 거쳐
정상 머지했다. EH-SUPPORT-1은 같은 당시 모집단의 가격 지원을 실제로 측정한다.
`intraday-sequential-scenario-support-v1.json`에 CB/CC 입력, 원래 달력,
같은 날 15·20·60분 및 전체 지원, 정확한 전 세션, 비교 기준 미인증 상태를 고정했다.
가격 시각은 완료+2분 가정이며 가격 결측·충돌·늦은 값·장 밖을 분리한다.

새 임시 가격 인덱스는 STARTED 뒤 인증된 CC에서만 만든다. 봉인된 옛 인덱스는
건드리지 않는다. 새 인덱스의 바이트를 별도 CC 순회로 대조하고 전체 EOF를
검사한 뒤, 저장 지원 행 전체를 독립 가격 계산과 대조한다. 원래 S1·S2·합집합·
교집합과 날짜·종목별 분모를 결과로 보존한다. 전일이 완전하더라도 서로 다른 날의
가격 기준이 인증된 것으로 간주하지 않는다.

원래 규모의 발명 입력을 단일 ordinary 작업자 한도에서 생성하고 새 인덱스·
저장·독립 검산까지 실행했다. 257일·5,158좌표·1,002,211행 및 6,597,703바이트
결과를 검증했고 CPU 34.118초, 최대 주소공간 44,720KiB였다. 조정자 32MiB
주소공간의 소스·계획 로딩 검사도 통과했다. 세 역할의 전체 운송·원영수증 자격은
정상 머지 이후의 별도 검사다.

고정된 private runtime과 독립 영수증 감사 코드의 SHA만 공개 등록에 둔다.
전체 합성 qualification-v1에서 동일 소스·런타임·저널·자원 및 종료 ACK를 확인하고
별도 원영수증을 감사한 뒤에만 실제 actual1이 원본을 읽을 수 있다. 실제 원본 지원
측정과 모델 비교·손익의 결론은 각각 별도 기록으로 남긴다.

## 2026-11-07 조건부 개장 범위 사건·경로 지원 등록

가격 지원 단위의 별도 검토·필수 CI·정상 머지(PR #410) 뒤 전체 합성과 실제
검산을 마쳤다. 전일 고점의 요구조건을 충족하지 못하고 당일 첫 판단에 자료 지원이
있어, 손익을 계산하기 전에 조건부 후속 하나를 개장 첫 15분 고가로 고정했다.
실제 수치와 실행 원영수증은 로컬에 보존한다. `EH-OPEN-1`의 고정 명세는
`intraday-sequential-opening-support-v1.json`이다.

첫 15분의 고가를 개장 후 17분에 고정하고 22분부터 완료 5분봉으로 판단한다.
첫 접근 뒤 돌파가 보이면 같은 사건에 별도 질문을 붙인다. 접근 질문 경계는
`T±2b`다. 돌파는 돌파봉 저가와 `T-b` 중 낮은 값을 하단으로 둔다. 상단은
당시 관측된 같은 세션의 확인된 스윙 고가 중 종가 위 가장 가까운 값이다. 스윙은
연속된 세 고가에서 `왼쪽 < 가운데 ≥ 오른쪽`으로 정의한다. 당일 연속 이력에
해당 값이 없을 때만 현재 종가에 하단 거리의 두 배를 더한다. 예측 기한은 원래
거래 사건의 만료와 구분한다.

5·15·30분 경로와 미확인·미지원을 함께 집계한다. 개장 첫 한 시간, 날짜와
종목의 집중도, S1·S2·교집합·합집합을 보존한다. 같은 저장본의 동일 좌표를
생산과 독립 기준 계산에서 비교하고 행·EOF·원영수증을 검산한다. 이 오프라인
감사 출력은 후속 관측과 결과를 포함하므로, 모델 입력은 별도의 시점 제한 투영을
먼저 저장해 결과를 연결한다. 이 단계에는 가격수익률이나 모델 적합이 없다.

원본 지원 단위의 사본이나 영수증을 덮어쓰지 않는다. 이번 등록의 별도 자격과
감사, 고정된 첫 실제 실행을 완료한 뒤 동일 후보 모집단의 순차 경로 비교로 간다.

미결정인 동일 질문에서 완료·가용한 접두사만으로 불가능해진 경로를 제거하는
합성 갱신도 검증한다. 5분이 흘렀더라도 5번째 분봉이 가용해지기 전에는 그 구간을
닫지 않는다. 기준 구역 재시험을 확인하면 직접 확장 경로를 제외한다. 공백·확정
또는 잔여 확률 0에서는 새 예측을 생성하지 않는다. 이 갱신은 모델 적합이 아니다.

발명 257일·5,158좌표·1,002,211행의 작업자 진단에 네 접근 경로와 접촉 순서
불명 사례를 모두 넣었다. 저장과 원본 독립 계산 대조까지 11,203,749바이트,
CPU 34.455초, 최대 주소공간 44,736KiB였다. 이 진단은 정상 머지의 세 역할
전체 실행 및 별도 원영수증 자격을 대체하지 않는다.

PR #411 첫 최종 Python CI에서 `ubuntu-latest`가 Ubuntu 26.04를 배정했고,
관리형 CPython 3.12.16을 사용한 프로세스의 가상 주소공간이 기존 검사 상한을
넘었다. PR #410의 통과 러너와 로컬 WSL은 Ubuntu 24.04의 시스템 CPython
3.12를 사용했다. Python CI를 그 플랫폼과 실행 파일 경로에 고정한다. 검사
대상, 필수 체크와 프로세스 자원 한도는 기존대로 둔다.

## 2026-11-07 판단 시점 특징·경로 라벨 분리 등록

`EH-OPEN-1`의 전체 합성 자격, 독립 원영수증 감사, 최초 실제 사건·경로
측정을 완료했다. 개장 범위 돌파는 관측 자료 안에서 빈도와 경로 표본이
확보됐고, 개장 첫 한 시간과 재시험 후 확장에는 더 좁은 지원이 남았다.
사건 감사 표에는 미래 결과도 있으므로 모델 입력을 그 표에서 가져오지 않는다.

`intraday-sequential-forecast-snapshot-v1.json`에 `EH-SNAPSHOT-1`을 등록한다.
